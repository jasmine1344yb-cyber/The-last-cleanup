# 남길 수 있는 것들 | The Last Cleanup

> **누군가의 방을 정리한다는 것은, 무엇을 남기고 무엇을 지우는 일일까?**

**인터랙티브 스토리텔링 프로젝트 · 1인칭 3D 탐색 게임 · 프로토타입 v0.4**

## 프로젝트 소개

플레이어는 낯선 방에 들어간 청소업자가 되어 물건을 발견하고 정리한다. 처음에는 명백한 쓰레기를 버리는 단순한 업무처럼 보인다. 그러나 사진, 인형, 칫솔, 새 구두 등 누군가의 삶이 묻어 있는 물건을 만날수록 청소라는 행동의 의미가 달라진다.

이 프로젝트의 중심 질문은 **“버려야 할 물건과 남겨야 할 흔적을 누가 결정하는가?”**이다.

현재 공개된 파일은 완성작이 아닌 **제작 중인 3D 프로토타입**이다. 아래의 일부 서사·구성 요소는 앞으로 검토하고 발전시킬 계획이며, 현재 버전에 모두 구현된 것은 아니다.

## 기획 의도

이 작품은 거창한 설명이나 직접적인 대사보다 플레이어가 직접 물건을 **발견하고, 살피고, 정리하는 반복 행동**으로 감정이 형성되는 경험을 지향한다.

- **처음:** 물건을 효율적으로 버리는 청소 업무
- **중간:** 물건에 담긴 사연을 추측하며 판단을 망설이는 과정
- **마지막:** 같은 정리 행동이 누군가의 흔적을 지우는 선택처럼 느껴지는 순간

핵심은 조작을 복잡하게 만드는 것이 아니라 **이전 경험이 다음 물건을 보는 방식과 선택을 바꾸게 하는 것**이다.

## 제작 과정

| 단계 | 기획 및 구현 방향 |
|---|---|
| 초기 기획 | 관객이 낯선 방에서 물건을 버리며 의미를 재해석하는 인터랙티브 경험 |
| 전개도 설계 | 공간 배치, 이동 동선, 물건을 발견하는 순서 설계 |
| 규칙 실험 | 단순 쓰레기는 버리지만 개인적인 물건을 만난 뒤 판단이 어려워지는 구조 |
| 프로토타입 | 2D 기반 실험에서 1인칭 3D 저폴리 탐색 방식으로 확장 |
| 현재 단계 | 공간의 설득력, 거주자의 삶, 선택의 결과, 감정 변화 개선 |

## 게임 경험과 조작

- **형식:** 브라우저 기반 HTML 게임 프로토타입
- **시점:** 1인칭 3D 탐색
- **핵심 행동:** 이동, 공간 살피기, 물건 발견과 정리
- **목표 감정:** 무심함 → 호기심 → 망설임 → 여운

정확한 조작법과 구현 범위는 업로드된 프로토타입의 게임 내 안내를 기준으로 한다.

> **중요:** GitHub 저장소에서 HTML 파일을 보는 것과 브라우저에서 게임을 실행하는 것은 다르다. 실행 링크를 제공하려면 별도의 웹 배포 설정이 필요하다.
>
> `index.html`의 비밀번호 입력 화면은 **연출용**이며, 보안 기능이 아니다. 정적 웹페이지의 코드와 게임 파일은 접근 가능한 사용자에게 노출될 수 있다. 실제 비공개 공유는 저장소의 Private 설정과 GitHub 협업자 권한, 또는 인증 기능이 있는 호스팅 서비스를 이용해야 한다.

## 다음 개발 목표

## 수업과의 연결

이 프로젝트는 인터랙티브 스토리텔링 수업에서 **반복하는 행동에 기억과 감정이 쌓이는 구조**를 연구하며 발전하고 있다. *Papers, Please*의 단순한 서류 심사 행위가 점차 윤리적 선택으로 변화하는 방식을 참고하되, 본 작품은 물건을 버리는 행위에 초점을 맞춘다.

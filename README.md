# THE LAST CLEANUP

**고독사 현장 정리를 소재로 한 1인칭 3D 인터랙티브 내러티브 게임**  
Prototype v17.2 · 2026.11.24

> 누군가의 마지막 흔적을 치웠지만, 거리의 하루는 계속되고 있었다.

## 1. 프로젝트 소개

《THE LAST CLEANUP》은 고독사 현장을 정리하는 작업자가 되어, 한 사람의 삶이 남아 있는 공간을 직접 탐색하고 청소하는 게임이다. 플레이어는 반지하 주거 공간에 진입해 쓰레기와 생활용품을 정리하고, 그 과정에서 거주자의 일상을 짐작할 수 있는 흔적을 발견한다.

청소를 통해 공간은 점차 정돈되지만, 동시에 그곳에 살았던 사람의 흔적도 사라진다. 게임은 이러한 모순을 통해 평범한 일상의 의미와 한 사람의 부재를 생각해 보도록 유도한다.

## 2. 기획 의도

- **행동을 통한 서사 전달:** 인물의 사연을 직접 설명하기보다 물건, 공간, 청소 행위를 통해 플레이어가 스스로 이야기를 발견하도록 설계했다.
- **청소의 물리적·심리적 부담:** 좁은 통로, 어둠, 쌓인 물건, 악취를 이동과 상호작용의 제약으로 구현했다.
- **일상의 흔적과 부재:** 손글씨 메모, 식당 쿠폰, 월세 봉투, 사용하지 않은 구두 등 평범한 물건을 통해 미처 이어지지 못한 일상을 드러낸다.
- **일상의 지속:** 시작과 끝에 등장하는 동네 식당을 통해 한 사람의 삶이 멈춘 이후에도 다른 사람들의 일상은 이어진다는 대비를 전달한다.

## 3. 게임 진행 방식

| 단계 | 진행 내용 |
| --- | --- |
| 프롤로그 | 동네 식당에서 식사를 마치고 쿠폰에 도장을 받는다. |
| 현장 진입 | 장애물이 쌓인 반지하 계단을 통과하고, 막힌 현관문 대신 부엌 창문으로 진입한다. |
| 부엌 | 일반 쓰레기를 정리하고 손전등을 발견한다. |
| 거실 | 생활용품과 통로의 짐을 정리하며 악취에 대응한다. |
| 화장실 | 몸을 낮춰 진입하고 개인용품을 정리하며 거울을 닦는다. |
| 서재 | 책과 달력 등을 정리하고 생활의 흔적을 살핀다. |
| 침실 | 장애물을 넘어 침구와 숨겨진 수납 공간을 조사한다. |
| 거실 재방문 | 발견한 물건을 이용해 잠긴 서랍을 열고 남은 생활용품을 정리한다. |
| 현관 및 에필로그 | 마지막 정리를 마친 뒤 밖으로 나가 아침에 방문했던 식당을 다시 마주한다. |

## 4. 주요 시스템

### 1인칭 탐색 및 물리적 이동

- WASD 이동, 마우스 시점 전환, 점프 및 웅크리기
- 계단, 가구, 상자, 낮은 창틀 등 공간별 장애물과 충돌 처리
- 몸을 낮추거나 뛰어넘어야 통과할 수 있는 경로
- 1인칭 시점에 표시되는 3D 신체와 작업용 장갑

### 물건별 청소 인터랙션

모든 물건을 동일한 버튼으로 제거하는 대신 물건의 종류에 따라 다른 조작을 요구한다.

- 쓰레기 줍기, 상자와 옷 끌어내기, 흩어진 물건 쓸어 담기
- 옷더미를 좌우로 헤집기, 거울의 물때를 문질러 닦기
- 창문 걸쇠와 서랍 잠금 원판 조작
- 물건을 3D로 회전하고 확대해 세부 흔적 관찰하기
- 장애물을 제거하면 숨겨진 물건이나 새로운 통로가 드러나는 단계별 진행 구조

### 악취 생존 및 회복

- 거실 이후 특정 위험 구역에 머무르면 공기 게이지가 감소한다.
- 공기가 부족해지면 시야가 어두워지고 호흡 및 경고 효과가 나타난다.
- 공기 게이지가 소진된 상태가 지속되면 체력이 감소한다.
- 이미 정리한 구역으로 돌아가 공기를 회복할 수 있다.
- 체력이 모두 소진되면 이전에 정리한 안전 구역으로 이동하며, 완료한 청소는 유지된다.

### 조명과 단서 스캔

- 주방에서 손전등을 발견한 뒤 어두운 공간을 탐색할 수 있다.
- 복도 전등 스위치 및 화면 밝기 조절 기능을 제공한다.
- 현장 스캔 모드에서 청소 후 드러나는 세 가지 흔적을 조사할 수 있다.
- 물건 조사와 단서 발견을 통해 거주자의 일상을 간접적으로 이해하게 한다.

### 그래픽 및 사운드

- WebGL 기반 3D 공간, 재질 텍스처, 조명 및 그림자
- 플레이어 신체에 원사이드(One-Sided) 렌더링 적용
- 발걸음, 물건 정리, 스위치, 호흡 등 행동에 대응하는 효과음
- 위험 구역에 따라 변화하는 앰비언스와 호흡 사운드

## 5. 조작법

| 키 / 입력 | 기능 |
| --- | --- |
| W / A / S / D | 이동 |
| 마우스 이동 | 시점 전환 |
| 방향키 | 시점 전환 보조 |
| Space | 점프 |
| C | 웅크리기 / 일어서기 |
| E / 좌클릭 | 물건 집기, 청소, 상호작용 |
| 마우스 좌우·상하 이동 | 물건 끌기, 쓸기, 뒤지기, 닦기 및 잠금 조작 |
| R / 우클릭 | 물건 자세히 보기 및 3D 회전 모드 |
| 마우스 휠 | 물건 확대 / 축소 (관찰 모드) |
| Q | 작업 취소 또는 물건 내려놓기 |
| F | 손전등 켜기 / 끄기 (획득 후) |
| V | 현장 단서 스캔 켜기 / 끄기 |
| B | 화면 밝기 조절 |
| M | 사운드 켜기 / 끄기 |
| Esc | 일시정지 또는 관찰 종료 |

창문은 걸쇠를 푼 뒤 **C + Space + W**를 이용해 직접 기어들어갈 수 있다. 진행 중 화면에 표시되는 상황별 안내를 참고한다.

## 6. 실행 방법

1. ZIP 파일을 내려받아 압축을 해제한다.
2. `index.html`과 `assets` 폴더가 같은 위치에 있는지 확인한다.
3. `index.html`을 Chrome 또는 Microsoft Edge로 실행한다.
4. 프롤로그를 진행하고 청소 현장으로 이동한다.

PC와 키보드·마우스 사용을 권장한다. 별도의 게임 엔진 설치나 빌드 과정은 필요하지 않다. 마우스 시점 연결이 해제되면 게임의 연결 버튼 또는 계속하기 버튼을 사용한다.

## 7. 기술 구성 및 파일 구조

- HTML5 / CSS / JavaScript
- WebGL: 3D 렌더링, 카메라, 충돌 및 물건 선택
- Web Audio API: 효과음 및 앰비언스
- Pointer Lock API: FPS 마우스 시점 제어
